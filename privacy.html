Política de Privacidade — SussurosDashboard

Última atualização: 2 de novembro de 2026

1. Sobre o painel

O SussurosDashboard é um projeto independente executado localmente no computador do operador para organizar publicações e consultar métricas das contas que ele decide conectar.

2. Dados acessados

Conforme as permissões concedidas e aprovadas pelas plataformas, o painel pode acessar identificadores de conta, nome público, informações de perfil, publicações e métricas como visualizações, curtidas, comentários, compartilhamentos e seguidores/inscritos. Os dados disponíveis dependem da API e das permissões autorizadas.

3. Uso dos dados

Os dados são usados para exibir métricas, organizar histórico local e executar ações solicitadas pelo operador. O projeto não se destina a vender ou alugar dados pessoais.

4. Armazenamento e compartilhamento

Na configuração atual, o painel roda localmente. Tokens e configurações podem ser guardados no arquivo local .env; métricas e registros de publicações podem ser guardados em banco SQLite local. O operador deve proteger o computador, os arquivos, cópias de segurança e credenciais. O painel envia solicitações às plataformas conectadas para realizar as funções solicitadas. As plataformas tratam dados segundo suas próprias políticas.

5. Retenção e exclusão

Os dados locais permanecem até serem excluídos pelo operador. Para interromper o acesso de uma plataforma, revogue a autorização nas configurações dela e remova as credenciais locais. Isso pode não apagar registros já armazenados localmente.

6. Segurança

Nenhum sistema é totalmente seguro. Mantenha o computador atualizado, limite o acesso aos arquivos e nunca exponha tokens, segredos de cliente ou arquivos de autenticação.

7. Serviços de terceiros

O uso das APIs depende dos termos, permissões e políticas do TikTok, Instagram/Meta e YouTube/Google.

8. Crianças e adolescentes

O painel não foi desenvolvido especificamente para crianças. O operador deve cumprir as regras aplicáveis e os termos das plataformas conectadas.

9. Alterações

Esta política pode ser atualizada quando as funções ou práticas mudarem. A versão atual será publicada nesta página.
